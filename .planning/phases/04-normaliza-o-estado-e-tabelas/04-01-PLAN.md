# Phase 4 Plan 01: Normalizadores e Persistência IndexedDB

<objective>
Criar `MoldeNormalizers` com campos derivados de pedidos, contas e indicadores; `MoldeStore` com IndexedDB; integrar normalização automática pós-validação e restauração do dataset ao abrir o app navegando para `#executivo`.
</objective>

<must_haves>
- Normalização dispara automaticamente após validação `valid` ou `valid_with_warnings`
- Dataset completo persiste em IndexedDB e restaura no boot
- Campos derivados seguem `04-CONTEXT.md` D-07..D-13
- Substituir planilha re-normaliza e atualiza store
- Sem ECharts, KPIs ou dashboards reais
</must_haves>

<threat_model>
## Ameaças e mitigações

- **T-04-01: Pipeline inflado como receita.** `Aguardando Aprovação` deve mapear para `Pipeline / orçamento`, nunca `Pedido ativo`. Mitigação: mapa estrito em `normalizers.js`.
- **T-04-02: Perder workbook entre validação e normalização.** Mitigação: normalizar no mesmo `handleUploadSelection` antes de descartar referência.
- **T-04-03: localStorage estourar com dataset.** Mitigação: IndexedDB apenas em `store.js`.
- **T-04-04: Indicadores inventados.** Mitigação: catálogo fixo + classificação manual/calculável/indisponível sem síntese numérica.
</threat_model>

- `DB_VERSION = 1`
- `DATASET_KEY = "current"`

Object store `dataset` com `keyPath: "id"` ou chave fixa `"current"`.

Snapshot shape:
```js
{
  id: "current",
  pedidos: [],
  contas: [],
  indicadores: [],
  importMeta: { pedidos: {}, contas: {}, indicadores: {} },
  normalizedAt: ISO string
}
```

API:
- `open()` Promise
- `loadDataset()` → snapshot | null
- `saveDataset(snapshot)`
- `upsertSource(kind, rows, metadata, validationReport)` merge por kind, atualiza `importMeta[kind]` com fileName, importedAt, validationStatus
- `clearDataset()` opcional para testes

Usar `indexedDB.open`; tratar upgrade em `onupgradeneeded`.
</action>

<action>
Em `index.html`, adicionar antes de `js/app.js`:
```html
<script src="js/normalizers.js" defer></script>
<script src="js/store.js" defer></script>
```

Em `js/app.js`:

1. Adicionar `appState = { dataset: null, restoredFromStore: false }`.

2. Boot async IIFE no final:
   - `const snapshot = await MoldeStore.loadDataset()`
   - se existir: `appState.dataset = snapshot`, `appState.restoredFromStore = true`, se hash vazio ou `#upload` → `location.hash = "executivo"`

3. Em `handleUploadSelection`, após `validateWorkbook` com status `valid` ou `valid_with_warnings`:
   - `const { rows } = MoldeNormalizers.normalizeWorkbook(workbook, kind)`
   - `appState.dataset = await MoldeStore.upsertSource(kind, rows, metadata, validationReport)`

4. Em erro de validação `invalid`, não alterar dataset daquela fonte (manter anterior se houver).

5. Substituir planilha já segue mesmo fluxo (re-normaliza automaticamente).

Não implementar tabelas/filtros neste plano.
</action>
