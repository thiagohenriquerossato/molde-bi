<action>
Criar `js/metrics.js` expondo `window.MoldeMetrics`.

Constantes:
```js
const RECEITA_ATIVA_GRUPOS = ["Pedido ativo", "Entregue"];
const PIPELINE_GRUPO = "Pipeline / orçamento";
const CANCELADO_GRUPO = "Perdido / cancelado";
const DESPESA_FIXA_KEYWORDS = ["SALARIO", "SALÁRIO", "ALUGUEL", "INTERNET", "TELEFONE", "CONTADOR", "ENERGIA", "ÁGUA", "AGUA", "CONDOMINIO", "CONDOMÍNIO", "FIXA"];
```

Helpers:
- `isReceitaAtiva(row)` → `RECEITA_ATIVA_GRUPOS.includes(row.situacao_grupo)`
- `isPipeline(row)` → `row.situacao_grupo === PIPELINE_GRUPO`
- `isCancelado(row)` → `row.situacao_grupo === CANCELADO_GRUPO`
- `isDespesaFixa(row)` → keyword match em classificacao+categoria normalizadas
- `sumField(rows, getter)` → safe sum
- `formatMonthKey(dateOrString)` → `YYYY-MM`

`computeExecutiveKpis(pedidos, contas)` retorna objeto:
```js
{
  receitaAtiva, valorRecebido, valorPendente,
  despesasTotais, despesasPagas, despesasAbertas, contasVencidas,
  resultadoCompetencia, ticketMedio,
  pedidosTotais, pedidosEntregues, pipelineValor, pipelineCount
}
```

Regras:
- `receitaAtiva`: sum `valor_final` where `isReceitaAtiva`
- `valorRecebido`: sum `valor_pago` where NOT `isCancelado`
- `valorPendente`: sum `valor_pendente` where NOT `isCancelado`
- `despesasTotais`: sum `valor` contas
- `despesasPagas`: sum `valor` where `pago` true
- `despesasAbertas`: sum `valor` where NOT `pago`
- `contasVencidas`: sum `valor` where `status_pagamento === "Vencido"`
- `resultadoCompetencia`: `receitaAtiva - despesasTotais`
- `ticketMedio`: sum `valor_final` non-cancelled / count non-cancelled (0 if count 0)
- `pedidosTotais`: count non-cancelled
- `pedidosEntregues`: count `situacao_grupo === "Entregue"`
- `pipelineValor` / `pipelineCount`: sum/count pipeline only

Agregações mensais (para charts):
- `aggregateRevenueExpenseByMonth(pedidos, contas)` → `[{ month, receitaAtiva, despesas, resultado }]`
- `aggregateReceivedPendingByMonth(pedidos)` → `[{ month, recebido, pendente }]`
- `aggregateFixedVariableByMonth(contas)` → `[{ month, fixa, variavel }]`
- `aggregateOrdersByGroup(pedidos)` → `[{ grupo, count, valor }]`
- `topClassifications(contas, limit=10)` → `[{ label, value }]`
- `topVendorsByRevenue(pedidos, limit=10)` → `[{ label, value }]` using receita ativa only

Exceções:
- `getOverdueContas(contas, limit=10)` → filter `status_pagamento === "Vencido"`, sort `dias_atraso` desc
- `getUpcomingContas(contas, limit=10)` → filter `status_pagamento === "Próximos 7 dias"`, sort `data_vencimento` asc

Exportar `formatCurrency(value)` usando `Intl.NumberFormat("pt-BR", { style: "currency", currency: "BRL" })`.
</action>
