<action>
Adicionar a `MoldeMetrics`:

`computeFinanceKpis(contas)` retorna:
```js
{
  totalContas, totalPago, totalAberto, totalVencido,
  venceHoje, vence7, vence30,
  mediaMensalDespesas,
  maiorFornecedor: { nome, valor }, maiorClassificacao: { nome, valor },
  percentualFixas, percentualVariaveis
}
```
Regras:
- `totalContas` = sum `valor`; `totalPago` = sum onde `pago`; `totalAberto` = sum onde `!pago`; `totalVencido` = sum onde `status_pagamento === "Vencido"`.
- `venceHoje` = sum status "Vence hoje"; `vence7` = sum status ∈ {"Vence hoje","Próximos 7 dias"}; `vence30` = sum status ∈ {"Vence hoje","Próximos 7 dias","Próximos 30 dias"}.
- `mediaMensalDespesas` = soma total / nº meses distintos em `mes_vencimento` (0 se nenhum).
- `maiorFornecedor`/`maiorClassificacao` = maior `sum(valor)` agrupado por `fornecedor`/`classificacao` (nome "—" e valor 0 se vazio).
- `percentualFixas` = sum(fixas)/total*100 (isDespesaFixa), `percentualVariaveis` = 100 − fixas (0 se total 0).
Reusar `sumField`, `isDespesaFixa`, `monthKeyFromConta`.
</action>

<acceptance_criteria>

- `node --check js/metrics.js` exit 0.
</acceptance_criteria>
