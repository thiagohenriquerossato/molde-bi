# Phase 4 Plan 02: Filtros Globais e Painel na Topbar

<objective>
Implementar `MoldeFilters` com estado compartilhado, painel colapsável na topbar visível em todas as páginas, multi-seleção categórica, período contextual e ação limpar filtros.
</objective>

<must_haves>
- Filtros globais na topbar em todas as rotas
- Período usa data_cadastro (pedidos) e data_vencimento (contas) conforme contexto
- Multi-seleção em campos categóricos
- Limpar filtros reseta estado e chips
- Base de Dados consumirá filtros no plano 03
</must_haves>

<threat_model>
## Ameaças e mitigações

- **T-04-05: Filtros só na Base de Dados.** Mitigação: painel na topbar renderizado em `renderShell` ou equivalente global, não só em `#base-dados`.
- **T-04-06: Período errado em contas.** Mitigação: `applyFilters` recebe `kind` e usa `data_vencimento` para contas.
- **T-04-07: Salvar visão v2 no escopo.** Mitigação: não adicionar botão salvar visão.
</threat_model>

<action>
Criar `window.MoldeFilters` com:

`createDefaultState()` retornando:
```js
{
  search: "",
  year: null,
  month: null,
  periodFrom: null,
  periodTo: null,
  valueMin: null,
  valueMax: null,
  pedidos: {
    situacao: [], situacaoGrupo: [], vendedor: [], cliente: [],
    formaEntrada: [], formaSaldo: [],
    comPendente: false, semCliente: false, semDataPrevista: false,
    entregueNoPrazo: false, atrasado: false, cancelado: false, aguardandoAprovacao: false
  },
  contas: {
    statusPagamento: [], fornecedor: [], classificacao: [], categoria: [], conta: [], parcela: [],
    pago: null, vencido: false, venceHoje: false, vence7: false, vence30: false,
    semValor: false, semClassificacao: false, semConta: false
  }
}
```

`applyFilters(rows, kind, state)`:
- `kind === "pedidos"`: filtrar por `data_cadastro` / `mes_cadastro` para ano/mês/período
- `kind === "contas"`: filtrar por `data_vencimento` / `mes_vencimento`
- busca livre: match em qualquer string field
- multi-select OR dentro do campo, AND entre campos
- toggles booleanos conforme lista em `docs/resume.md` §5

`getActiveChips(state)` → `{ id, label, removeKey }[]`
`clearAll()` → default state
`cloneState(state)` para imutabilidade

Exportar helpers `getDistinctValues(rows, field)` para popular selects na UI.
</action>

- Contém lógica distinta para pedidos vs contas (grep `pedidos` e `contas` no arquivo).
- `node --check js/filters.js` exit 0.
