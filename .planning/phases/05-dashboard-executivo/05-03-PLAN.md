# Phase 5 Plan 03: Integração da Página Executivo

<objective>
Conectar `#executivo` com render real: 12 KPIs em blocos, 6 gráficos ECharts, tabelas de exceção e refresh automático quando filtros globais mudam.
</objective>

<must_haves>
- Rota `executivo` usa `renderExecutivoPage` customizado
- KPIs, gráficos e listas usam dataset filtrado via `MoldeFilters`
- Pipeline visualmente isolado com badge
- `onFilterStateChanged` atualiza executivo
- Charts disposed ao re-render
- Empty state quando sem dataset ou sem `canContinueToDashboards()`
</must_haves>

<threat_model>
## Ameaças e mitigações

- **T-05-04: Dashboard fake permanece.** Mitigação: remover banner Fase 4 "dashboards chegam na Fase 5" na rota executivo; renderizar dados reais.
- **T-05-05: Filtros não afetam executivo.** Mitigação: `onFilterStateChanged` chama `mountExecutivoDashboard()`.
</threat_model>

## 1. Renderer da página executivo

<task>
id: `05-03-01`
type: `feature`
files:
- `js/app.js`

<read_first>
- `js/app.js`
- `js/metrics.js`

- `.planning/phases/05-dashboard-executivo/05-CONTEXT.md`
- `.planning/phases/05-dashboard-executivo/05-UI-SPEC.md`
</read_first>

<action>
Em `js/app.js`:

1. Adicionar `let executiveChartInstances = [];` no topo.

2. Na definição `routes.executivo`, adicionar `render: renderExecutivoPage` e atualizar `badge` para `"Dados carregados"` quando aplicável (ou manter dinâmico no header).

3. Implementar `renderExecutivoPage(route)`:
   - Se `!canContinueToDashboards()` → `renderEmptyPage(route)` (exige pedidos+contas validados)
   - Senão retornar HTML com:
     - `createPageHeader(route)` com badge "Dados carregados"
     - 4 metric blocks conforme `05-UI-SPEC.md` com placeholders `data-metric="receitaAtiva"` etc.
     - `.executive-charts-grid` com 6 `.chart-panel` e `data-chart` attributes + `.chart-canvas` divs
     - `.executive-exceptions` com 2 cards e containers `data-exception="overdue"` e `data-exception="upcoming"`

4. Implementar `renderMetricCard(label, value, options)` helper retornando HTML string.

5. Implementar `mountExecutivoDashboard()`:
   - Guard: `getRouteFromHash() !== "executivo"` ou `!canContinueToDashboards()` → return
   - `const pedidos = MoldeFilters.applyFilters(appState.dataset.pedidos, "pedidos", filterState)`
   - `const contas = MoldeFilters.applyFilters(appState.dataset.contas, "contas", filterState)`
   - `const kpis = MoldeMetrics.computeExecutiveKpis(pedidos, contas)`
   - Atualizar cada `[data-metric]` com `MoldeMetrics.formatCurrency` ou count
   - Pipeline block: label `Pipeline (orçamento)`, badge `Não contabilizado na receita`, classe `metric-card--warning`
   - Dispose `executiveChartInstances` via `MoldeCharts.disposeExecutiveCharts`
   - Coletar chart container elements, chamar `MoldeCharts.renderExecutiveCharts(...)`
   - Guardar retorno em `executiveChartInstances`
   - Render exception tables HTML em `[data-exception="overdue"]` e `[data-exception="upcoming"]` usando `getOverdueContas` / `getUpcomingContas` — tabela compacta com colunas Fornecedor, Vencimento, Valor, Status; empty message se 0 rows

6. Em `renderCurrentRoute`, após innerHTML:
   ```js
   if (routeName === "executivo" && canContinueToDashboards()) {
     mountExecutivoDashboard();
   }
   ```

7. Em `onFilterStateChanged`, adicionar:
   ```js
   if (getRouteFromHash() === "executivo" && canContinueToDashboards()) {
     mountExecutivoDashboard();
   }
   ```
</action>
