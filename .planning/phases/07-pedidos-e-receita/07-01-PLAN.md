<objective>
Estender `MoldeMetrics` com os 15 KPIs de pedidos em 4 blocos temáticos, agregações mensais/funil/histograma e seletores das 6 tabelas de exceção, além dos estilos CSS da grade de gráficos e tabelas do Pedidos. Receita ativa via `isReceitaAtiva` — pipeline nunca entra no bloco Valores.

- Agregações: receita/pedidos/ticket/desconto por mês, funil situação, vendedores, pendente por status, top clientes, produção por mês, histograma ticket

- Campos derivados (`situacao_grupo`, `dias_producao`, `entregue_no_prazo`) usados como fonte — não recomputar
</must_haves>

<action>
Adicionar a `MoldeMetrics`:

`computePedidosKpis(pedidos)` retorna:
```js
{
  valores: {
    valorBruto, descontos, valorFinal, valorPago, valorPendente, ticketMedio
  },
  status: {
    totalPedidos, pedidosEntregues, pedidosCancelados, pedidosAtivos
  },
  pipeline: {
    pipelineCount, pipelineValorTotal
  },
  prazos: {
    descontoMedio, tempoMedioProducao, atrasoMedio, percentualEntregueNoPrazo
  }
}
```
Regras:
- Receita ativa = `pedidos.filter(isReceitaAtiva)`.
- **Valores (6):** somas de `valor_bruto`, `valor_desconto`, `valor_final`, `valor_pago`, `valor_pendente` sobre receita ativa; `ticketMedio` = sum(valor_final)/count (0 se count 0).
- **Status (4):** sobre conjunto filtrado completo — `totalPedidos` = count; entregues/cancelados/ativos filtram `situacao_grupo` ∈ {"Entregue","Perdido / cancelado","Pedido ativo"}.
- **Pipeline (1):** `pipelineCount` = count onde `situacao_grupo === "Pipeline / orçamento"`; `pipelineValorTotal` = sum(valor_final) pipeline (secundário, não entra em Valores).
- **Prazos (4):** `descontoMedio` = média de `valor_desconto/valor_bruto*100` sobre receita ativa com `valor_bruto > 0`; `tempoMedioProducao` = média `dias_producao` entregues com valor válido; `atrasoMedio` = média `dias_atraso` entregues com `dias_atraso > 0`; `percentualEntregueNoPrazo` = count(entregue_no_prazo === true) / count(entregues com datas válidas) × 100.
Reusar `isReceitaAtiva`, `isPipeline`, `sumField`, `formatCurrency`, `formatPercent`.
</action>

<acceptance_criteria>

- `rg "descontoMedio|percentualEntregueNoPrazo|pipelineCount" js/metrics.js`.
- `node --check js/metrics.js` exit 0.
</acceptance_criteria>

Adicionar a `MoldeMetrics`:

Agregações para gráficos:
- `aggregateRevenueByMonth(pedidos)` → `[{ month, valor }]` receita ativa por `mes_cadastro`
- `aggregateOrdersByMonth(pedidos)` → `[{ month, count }]` todos filtrados por `mes_cadastro`
- `aggregateTicketByMonth(pedidos)` → `[{ month, ticket }]` ticket médio receita ativa por mês
- `aggregateDiscountByMonth(pedidos)` → `[{ month, valor }]` sum desconto receita ativa por mês
- `aggregateProductionTimeByMonth(pedidos)` → `[{ month, dias }]` média `dias_producao` por `mes_entrega` (entregues válidos)
- `topClientsByRevenue(pedidos, limit=12)` → `[{ label, value }]` receita ativa
- `topVendorsByOrderCount(pedidos, limit=12)` → `[{ label, value }]` count todos filtrados
- `pendingByStatus(pedidos)` → `[{ label, value }]` sum(valor_pendente) por `situacao_grupo`, excluir cancelados
- `onTimeDeliverySplit(pedidos)` → `{ noPrazo, atrasado }` entregues com datas válidas
- `ticketHistogram(pedidos)` → `[{ label, value }]` bins de `valor_final` receita ativa (faixas: 0–500, 500–1k, 1k–2k, 2k–5k, 5k+)
- Reusar `aggregateOrdersByGroup`, `topVendorsByRevenue`, `monthKeyFromPedido`.

Seletores de exceção (sem limite):
- `getPedidosAtrasados(pedidos)` → `entregue_no_prazo === false`, sort `dias_atraso` desc
- `getPedidosEntreguesComPendencia(pedidos)` → `situacao_grupo === "Entregue"` e `valor_pendente > 0.01`, sort `valor_pendente` desc
- `getPedidosSemCliente(pedidos)` → `!cliente` ou `cliente_normalizado` vazio
- `getPedidosSemDataPrevista(pedidos)` → `!data_prevista`
- `getPedidosDescontoAlto(pedidos, threshold=0.20)` → `valor_desconto/valor_bruto >= threshold` com `valor_bruto > 0`, sort % desc
- `getPedidosPipelineAprovacao(pedidos)` → `situacao_grupo === "Pipeline / orçamento"`, sort `data_cadastro` asc
Exportar todas em `window.MoldeMetrics`.
</action>
