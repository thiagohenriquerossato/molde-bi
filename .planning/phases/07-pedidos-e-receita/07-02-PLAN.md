# Phase 7 Plan 02: Gráficos ECharts do Pedidos

<objective>
Adicionar `renderPedidosCharts(containers, pedidos, theme)` ao `MoldeCharts` com os 12 gráficos do Pedidos / Receita, incluindo funil de situação (pipeline distinto) e histograma de ticket. Reusar tema, cores e `dispose` do padrão das Fases 5 e 6.
</objective>

<must_haves>
- `renderPedidosCharts` instancia até 12 gráficos e retorna instâncias para dispose
- Funil usa `series.type = "funnel"` com pipeline em cor warning
- Gráficos de receita usam receita ativa — pipeline nunca como receita realizada
- Histograma usa bins pré-agregados de `ticketHistogram`
- Cores de `--chart-*`, tooltips pt-BR, locale currency
- Nenhum dado de contas/despesas
</must_haves>

## 1. renderPedidosCharts

<task>
id: `07-02-01`
type: `feature`
files:
- `js/charts.js`

<read_first>

- `js/metrics.js`
- `.planning/phases/07-pedidos-e-receita/07-RESEARCH.md`
- `.planning/phases/07-pedidos-e-receita/07-UI-SPEC.md`
</read_first>

<action>
Adicionar `renderPedidosCharts(containers, pedidos, theme)` a `MoldeCharts`, reusando `getChartColors`, `formatBrl`, `formatMonthLabel`, `initChart`, `baseTooltip`.

Containers (keys): `revenueMonth`, `ordersMonth`, `ticketMonth`, `ordersStatus`, `revenueVendor`, `ordersVendor`, `pendingStatus`, `discountMonth`, `topClients`, `onTimeDelivery`, `productionTimeMonth`, `ticketDistribution`.

Séries via `MoldeMetrics`:
1. `revenueMonth` — bar: `aggregateRevenueByMonth` (x=mês, y=valor, receita ativa).
2. `ordersMonth` — bar: `aggregateOrdersByMonth` (count todos filtrados).
3. `ticketMonth` — line: `aggregateTicketByMonth` (receita ativa).
4. `ordersStatus` — funnel: `aggregateOrdersByGroup`; pipeline com cor `--warning-fg` ou `--chart-*` distinto.
5. `revenueVendor` — bar horizontal: `topVendorsByRevenue` (limit 12, reverse, receita ativa).
6. `ordersVendor` — bar: `topVendorsByOrderCount` (limit 12).
7. `pendingStatus` — bar stacked: `pendingByStatus` (valor pendente por `situacao_grupo`).
8. `discountMonth` — line: `aggregateDiscountByMonth` (receita ativa).
9. `topClients` — bar horizontal: `topClientsByRevenue` (limit 12, reverse).
10. `onTimeDelivery` — pie rosca (`radius: ["40%","70%"]`): `onTimeDeliverySplit` (No prazo / Atrasado).
11. `productionTimeMonth` — line: `aggregateProductionTimeByMonth` (média dias).
12. `ticketDistribution` — bar: `ticketHistogram` (bins pré-agregados).

Todos com `aria.enabled`, `animationDuration: 300`, grid adequado, tooltip currency/percent conforme série. Retornar `instances.filter(Boolean)`.
</action>

<acceptance_criteria>
- `rg "renderPedidosCharts" js/charts.js`.
- `rg "type: \"funnel\"|ordersStatus" js/charts.js`.
- `rg "ticketDistribution|ticketHistogram|onTimeDelivery" js/charts.js`.
- `node --check js/charts.js` exit 0.
</acceptance_criteria>

<verify>
```sh
rg "renderPedidosCharts|funnel|ticketDistribution|onTimeDelivery" js/charts.js
node --check js/charts.js
```
</verify>
</task>
