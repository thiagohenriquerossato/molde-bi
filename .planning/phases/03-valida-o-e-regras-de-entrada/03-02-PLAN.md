# Phase 3 Plan 02: Painel de Validação e Fluxo para Dashboards

<objective>
Integrar `MoldeValidation` ao fluxo de upload existente: validação automática após leitura, painel `Resultado da validação` abaixo dos cards, badges `Válido`/`Com informações`/`Inválido`, listagem de achados conforme CONTEXT e CTA `Continuar para dashboards` habilitado apenas quando Pedidos e Contas não tiverem erros críticos.
</objective>

<requirements_addressed>
- `IMP-04`: usuário recebe resumo claro de validação após cada workbook lido.
- `IMP-05`: usuário pode seguir para dashboards quando só houver alertas não críticos (warnings de limpeza).
</requirements_addressed>

<threat_model>
## Ameaças e mitigações

- **T-03-05: CTA liberado com dados inválidos.** Mitigação: `canContinueToDashboards()` exige `pedidos` e `contas` com status `valid` ou `valid_with_warnings`.
- **T-03-06: Indicadores bloqueando fluxo.** Mitigação: CTA ignora status de `indicadores`.
- **T-03-07: UI sem feedback de revalidação.** Mitigação: substituir planilha dispara leitura + validação e atualiza painel/bloco da fonte.
- **T-03-08: Listas longas quebram layout.** Mitigação: expansível `Ver todos (N)` para warnings; top 10 plano para críticos.
</threat_model>
