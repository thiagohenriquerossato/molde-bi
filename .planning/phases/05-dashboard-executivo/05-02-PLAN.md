# Phase 5 Plan 02: Gráficos ECharts do Executivo

<objective>
Criar `MoldeCharts` com 6 instâncias ECharts para o dashboard executivo, paleta pt-BR, lifecycle dispose/resize e séries que usam receita ativa (não pipeline).
</objective>

<must_haves>
- `window.MoldeCharts` renderiza 6 gráficos EXE-02
- Usa `MoldeMetrics` para dados
- `disposeExecutiveCharts()` limpa instâncias
- Paleta lê `--chart-1`..`--chart-5` de CSS
- Script `charts.js` antes de `app.js`, após `metrics.js`
</must_haves>

<threat_model>
## Ameaças e mitigações

- **T-05-03: Memory leak em hash routes.** Mitigação: `dispose()` em cada instância antes de re-init.
- **T-05-01: Pipeline em série de receita.** Mitigação: charts consumem apenas agregações `receitaAtiva` de `MoldeMetrics`.
</threat_model>

## 1. Criar `js/charts.js`

<task>
id: `05-02-01`
type: `feature`
files:

<read_first>

- `.planning/phases/05-dashboard-executivo/05-RESEARCH.md`
</read_first>

<action>
Criar `js/charts.js` expondo `window.MoldeCharts`.

Funções:
- `getChartColors()` → lê `getComputedStyle(document.documentElement)` para `--chart-1`..`--chart-5`, retorna array HSL strings
- `formatBrl(value)` → reuse ou delegate `MoldeMetrics.formatCurrency`
- `disposeInstances(instances)` → foreach `instance.dispose()`
- `renderExecutiveCharts(containers, pedidos, contas, theme)` → retorna array de instâncias

`containers` é mapa:
```js
{
  revenueExpenseResult: HTMLElement,
  receivedPending: HTMLElement,
  fixedVariable: HTMLElement,
  ordersStatus: HTMLElement,
  topClassification: HTMLElement,
  topVendors: HTMLElement
}
```

Implementar 6 charts:

1. **revenueExpenseResult** — combo bar: receita ativa, despesas; line: resultado. Data from `MoldeMetrics.aggregateRevenueExpenseByMonth`.
2. **receivedPending** — stacked bar mensal de `aggregateReceivedPendingByMonth`.
3. **fixedVariable** — stacked bar de `aggregateFixedVariableByMonth`.
4. **ordersStatus** — donut/pie de `aggregateOrdersByGroup` (pipeline fatia separada, cor warning).
5. **topClassification** — horizontal bar `topClassifications(contas, 10)`.
6. **topVendors** — horizontal bar `topVendorsByRevenue(pedidos, 10)`.

Opções ECharts:
- `grid: { left: 48, right: 16, top: 32, bottom: 32 }`
- Tooltip formatter BRL
- `aria: { enabled: true }`
- Sem animação excessiva; `animationDuration: 300`
- Dark mode: passar `theme` param (`"dark"` quando `document.documentElement.dataset.theme === "dark"`)

Exportar:
- `renderExecutiveCharts(containers, pedidos, contas, theme)`
- `disposeExecutiveCharts(instances)`
</action>

<acceptance_criteria>
- `js/charts.js` existe e define `window.MoldeCharts`.
- Contém `echarts.init`.
- Contém `dispose` (disposeExecutiveCharts ou disposeInstances).
- Contém `renderExecutiveCharts`.
- Contém referência a `MoldeMetrics`.
- `node --check js/charts.js` exit 0.
</acceptance_criteria>

<verify>
```sh
test -f js/charts.js
rg "window\\.MoldeCharts|renderExecutiveCharts|echarts\\.init|dispose" js/charts.js
node --check js/charts.js
```
</verify>
</task>
